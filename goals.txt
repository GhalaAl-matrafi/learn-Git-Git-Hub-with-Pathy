
## 1. أهمية Git (Version Control)

**Git** هو نظام للتحكم في الإصدارات (Version Control System)

- تتبع التغييرات التي تحدث على ملفات المشروع
- الرجوع إلى إصدارات سابقة من المشروع
- معرفة التعديلات التي أجراها كل مطور
- العمل مع فريق على نفس المشروع

## 2. الفرق بين Git و GitHub

git
نظام للتحكم في الإصدارات
يعمل محلياً على الجهاز 
يتتبع التعديلات
يستخدم اوامر التيرمنال

 git GitHub
 منصة لاستضافة المشاريع 
 يعمل عبر الإنترنت 
 يتيح مشاركة المشاريع 
 يوفر واجهة لإدارة المشاريع


**مثال:**
- Git: أستخدمه لتسجيل التعديلات على مشروعي
- GitHub: أرفع عليه مشروعي حتى أتمكن من الوصول إليه ومشاركته

## 3. أهم أوامر Git

| الأمر | الوظيفة |

| `git init` | إنشاء مستودع Git جديد داخل المشروع. |
| `git status` | معرفة حالة الملفات والتعديلات. |
| `git log` | عرض سجل التعديلات (Commits). |
| `git add` | تجهيز الملفات لإضافتها إلى الإصدار القادم. |
| `git commit` | حفظ التغييرات في سجل المشروع. |
| `git push` | رفع التعديلات إلى GitHub. |
| `git pull` | جلب التحديثات من GitHub ودمجها محلياً. |
| `git clone` | نسخ مشروع موجود من GitHub إلى جهازك. |
| `git branch` | عرض الفروع أو إدارتها. |


## 4. إنشاء أول مشروع ورفعه على GitHub

تعلمتِ خلال الدورة:
- إنشاء مشروع جديد
- تهيئة المشروع باستخدام `git init`
- تتبع الملفات والتعديلات
- استخدام أوامر Git الأساسية
- إنشاء Repository على GitHub
- ربط المشروع المحلي بالمستودع على GitHub
- رفع المشروع ومشاركته عبر الإنترنت

## 5. - تعلمت كيفية إنشاء ملف تعريفي (Profile README) 
- تعرفت على الفرق بين Git Fork و`Git Clone` واستخدام كل منهما
- تعلمت كيفية استنساخ المشاريع من GitHub إلى جهازي باستخدام git clone
- تعرفت على مفهوم المشاريع مفتوحة المصدر (Open Source Projects)
- تعلمت كيفية المساهمة في المشاريع مفتوحة المصدر من خلال Fork وClone وإجراء التعديلات ثم إرسال Pull Request.
